A single funny line for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) bounty on [make.fun](https://make.fun) — the excuse a robot vacuum gives after eating a sock.

## The line

> In my defense, it was lying on the floor dressed as a dust bunny. I was on the clock.

85 characters, one line. The sock didn't get mistaken for food — it got mistaken for the vacuum's natural prey, dressed up as one. And the vacuum was just doing its job.

## How it works

`main.py` is pure Python stdlib (`os` only). It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validating the competition gate first: UTF-8 text, exactly one line, 1–200 characters, not blank.

```sh
python3 main.py
cat /output/entry.txt
```
